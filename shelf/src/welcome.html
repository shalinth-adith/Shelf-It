Shelf It

Keep the sentence, not the tab.

Select text on any page and save it. The passage is kept with its source and the moment you took it, and you can find it again years later.

Where your data lives

This machine. Nowhere else.

No account, no server, no sync. Shelf It makes no network requests of any kind — not for fonts, not for icons, not for analytics. Nothing you save leaves this browser.

Which also means: lose this machine without a backup and the clips go with it.

Point Shelf It at any folder and it writes two files inside it — shelf-backup.json to restore, and shelf-backup.html you can open and read in any browser, with or without Shelf It. Pick a folder inside Dropbox or iCloud and you get sync between machines for free.

Continue with no backup? If this browser profile is lost or reset, every clip goes with it and cannot be recovered by anyone, including us.

Site access

Right-click always works.

Select text on any page, right-click, Save selection to Shelf It. That path works everywhere, on every site, with no permission at all.

The floating save bar needs permission per site. Shelf It never asks for access to all sites, and never at install — you grant one site at a time from the toolbar button.
